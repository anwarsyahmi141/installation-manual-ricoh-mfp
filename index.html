Can’t see your printer?

Add it using the machine’s IP address. On the printer, open User Tools / Settings → System Settings → Interface Settings to find the IPv4 address. On your PC, go to Settings → Bluetooth & devices → Printers & scanners → Add device, then choose Add manually.
