MANUAL INSTALLATION

Install step by step

For a network printer, get its IP address first and keep your PC on the same network.

4 STEPS
01

Download the PCL 6 driver

Open Ricoh’s official page above, choose your model and Windows 10/11, then download PCL 6 Driver. Most PCs use the 64-bit package.

02

Extract the downloaded file

Double-click the downloaded file and follow the prompts to extract it. Note where the files are saved; look for a folder containing DISK1 or oemsetup.inf.

03

Add the printer in Windows

Open Settings → Bluetooth & devices → Printers & scanners (Windows 11) or Settings → Devices → Printers & scanners (Windows 10). Select Add device, then Add manually if it is not found.

For network setup, choose Add a printer using a TCP/IP address and enter the printer’s IP address. For USB, connect the cable when Windows asks.

04

Select the extracted PCL 6 driver

When prompted to choose a driver, select Have Disk → Browse, open the extracted driver folder and select the matching oemsetup.inf file. Choose the Ricoh model PCL 6 entry, finish setup, then print a test page.

⌁
NETWORK INSTALL

Can’t see your printer?

Add it using the machine’s IP address. On the printer, open User Tools / Settings → System Settings → Interface Settings to find the IPv4 address. On your PC, go to Settings → Bluetooth & devices → Printers & scanners → Add device, then choose Add manually.
