# Ricoh MFP Setup Guide

A static website that helps Windows 10/11 users find their Ricoh MFP and follow a model-specific PCL 6 installation guide. Current IM families and newer MP families use Ricoh's `.exe` setup flow. Older MP 2500 and MP Cxxx1/xxx2 models show the Windows manual add-printer flow.

## Open it

Open `https://anwarsyahmi141.github.io/installation-manual-ricoh-mfp/` in a web browser. No build tools or server are required.

The landing page has model search and popular MFP shortcuts. For models in `ricoh-mfp-driver-link.txt`, the driver button opens that model's Ricoh support page. Other models open Ricoh Asia Pacific's official Office Solutions catalog. Choose the Windows version and download PCL 6.
